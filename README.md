# Клиент для Яндекс Книг

Неофициальная программа для чтения Яндекс Книг на Kindle с джейлбрейком. Это плагин со
своим простым интерфейсом, работает на KOReader. KOReader уже входит в сборку, отдельно
его ставить не нужно. Книги из подписки открываются только при активной подписке Яндекс Книг.

## Какие Kindle подходят

Важна версия прошивки. Её можно посмотреть на самом Kindle: Settings → Device Options →
Device Info.

| Прошивка | Что ожидать |
|---|---|
| 5.19.2 на Paperwhite 5 | проверено на устройстве |
| другие версии от 5.16.3 | сборка рассчитана на них, но на устройстве не проверялась |
| ниже 5.16.3 | не подходит: для этих прошивок сборки нет |

Если у вас другая модель или прошивка и программа заработала либо нет, напишите об этом в
[Issues](https://github.com/ioannde/kindle-yaknigi-client/issues).

## Установка

Сначала нужен джейлбрейк. Способ зависит от модели и прошивки, инструкции есть на
[kindlemodding.org](https://kindlemodding.org). Его вы делаете сами и на свой риск.

1. Скачайте `yaknigi-ko-kindlehf.zip` со страницы
   [релизов](https://github.com/ioannde/kindle-yaknigi-client/releases) и распакуйте архив.
2. Подключите Kindle к компьютеру по USB и скопируйте папки `extensions` и `documents` в
   корень Kindle. Если такие папки там уже есть, файлы нужно добавить к ним, не заменяя
   сами папки.
3. Безопасно извлеките Kindle.
4. Запустите программу одним из двух способов:
   - через KUAL: пункт «Клиент для Яндекс Книг»;
   - без KUAL, если это позволяет ваш джейлбрейк: файл «Клиент для Яндекс Книг» в списке
     книг.
5. Примите условия использования и войдите в Яндекс: наведите камеру телефона на QR-код и
   разрешите доступ, затем введите полученный код на Kindle.

Если у вас есть KPM, вместо шагов с 1 по 3 можно поставить пакет `yaknigi-ko_kindlehf.kpkg` с той
же страницы релизов.

## Что работает

- Вход в аккаунт Яндекса по QR-коду.
- Библиотека: «Читаю», «Хочу прочитать», «Прочитанные» и ваши полки. На обложках прочитанных
  книг стоит отметка.
- Каталог Яндекс Книг и поиск.
- Чтение книг: оглавление, выравнивание, переносы, способ листания, вертикальный или
  горизонтальный экран. Панели чтения открываются нажатием в верхней части экрана.
- Синхронизация с Яндексом в обе стороны: место чтения, закладки, выделения и заметки.
  Заметку можно сделать публичной или приватной.
- Отметка книги как прочитанной. Процент прочитанного при этом не меняется.
- Тёмная тема, выбор заставки и время ухода в сон.

Аудиокниги не поддерживаются. Книгу, которая есть только в аудио, программа открыть не
сможет и скажет об этом.

## Обновления

Раз в сутки при подключении к интернету программа смотрит, вышла ли новая версия, и
предлагает обновиться, напомнить позже или пропустить эту версию. Проверку можно отключить
в настройках, раздел «О программе». Если новая версия не запустится, вернётся прежняя.

Версию, которая меняет KOReader или файлы запуска, нужно ставить вручную. Программа об этом
скажет. Настройки и вход при обновлении сохраняются.

## Условия и лицензия

Программа не связана с Яндексом и Amazon. Пользуясь ею, вы принимаете
[условия использования](koreader/yaknigi.koplugin/TERMS.md). Лицензия: GNU GPL версии 3,
KOReader распространяется по GNU AGPL версии 3.

## Для разработчиков

### Своя сборка

Идентификатора приложения Яндекса в репозитории нет. Зарегистрируйте своё приложение на
[oauth.yandex.ru](https://oauth.yandex.ru) (без секрета, вход по коду, Redirect URI
`https://oauth.yandex.ru/verification_code`) и задайте его Client ID в секрете GitHub Actions
`YANDEX_CLIENT_ID`. Без него сборка останавливается с ошибкой. При запуске без сборки
идентификатор берётся из переменной окружения `YB_CLIENT_ID` или файла
`yaknigi/client_id.lua` с содержимым `return "..."`.

### Выпуск версии

Тег `vX.Y.Z` на `main` собирает программу и публикует релиз. Номер должен быть больше
прежнего, иначе обновление никому не придёт.
